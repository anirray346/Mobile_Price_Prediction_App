# Mobile Price Prediction App
## Streamlit App

This is a web application built using **Python** and **Streamlit**.

The app is deployed on **Streamlit Community Cloud** and provides an interactive interface for users.

## Features
- Interactive UI built with Streamlit
- Fast and lightweight web app
- Easy deployment on Streamlit Community Cloud

## Run Locally
1. Clone the repository
git clone https://github.com/anirray346/Mobile_Price_Prediction_App.git

2. Install dependencies
pip install -r requirements.txt
   
3. Run the app
streamlit run app.py


## Requirements
- Python 3.8+
- Streamlit
